---

**Settings → Activity** lists the important actions in your organization, newest first. Owners and administrators can open it.

## What it records

- Opportunity reviews, approvals, rejections, deferrals and assignments.
- Drafts, prepared changes, approved changes and reverts.
- GitHub tickets, repository connections and the GitHub App.
- Tracked changes, deployment confirmations and measurement requests.
- Scheduled job changes and spending limit changes.
- Search Console and Google Analytics connections.
- Member invitations and removals, and API key changes.
- Who may approve pull requests, for the organization and for each project.
- Agency access requests, acceptances and endings, and shared report branding changes.

Each entry shows the time, the person, the action and the project. **AI agent** marks an action that an AI client took through your API key or the MCP server. **Scheduled** marks an action that a scheduled job took.

## Filter and export

Filter by project, action or person. Click **Download CSV** to save up to 5,000 entries.

Relay keeps activity for one year.
